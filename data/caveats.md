# Caveats (carry these onto the screen/caption)
- Ring sizes are population **scaled** (radius ∝ population^0.45) so 51 circles fit; on-screen source line says "scaled". The game outcome is physics + chance, not a ranking or a judgment about any state.
- Census Vintage 2025 estimates will be superseded by Vintage 2026 (scheduled December 2026); rebuild data then.
- Debt to the Penny changes every business day; the doubling video is pinned to 2026-11-09. Re-pull before reposting.
- Median household income is real (2025 dollars), CPS ASEC; 2025 figure released 2026-09-15.
- Census API (api.census.gov) needs a free key; this run used the key-free CSV on www2.census.gov instead. Add a key to unlock ACS tables.
- The shell has no internet here: data was fetched through the web-fetch tool and transcribed values were verified with sum/subtotal checks.
